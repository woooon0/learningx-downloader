# Hanyang LearningX Downloader

mechaminu/learningx-downloader를 기반으로 한 한양대학교용 수정판입니다. 학교 공식 프로그램이 아닙니다.

## 설치와 사용
1. 이 폴더를 내려받습니다.
2. Chrome 확장 프로그램 관리 화면에서 개발자 모드를 켜고 압축해제된 확장 프로그램 로드로 이 폴더를 선택합니다.
3. learning.hanyang.ac.kr에서 본인 계정으로 로그인하고 접근 권한이 있는 강의를 재생합니다.
4. 확장 프로그램에서 영상 찾기, 파일 저장을 선택합니다.
5. Chrome 다운로드 목록에서 실제 완료 여부를 확인합니다.

현재 플레이어에 로드된 MP4, M4A, MP3 주소만 검사합니다. 서버가 다운로드 요청을 거부할 수 있으며, 403은 성공으로 처리하지 않습니다. 다운로드 요청 접수는 완료를 의미하지 않습니다. 출처 헤더 변경, 인증 우회, DRM 해제, 출석 변경 기능은 없습니다. 별도 다운로드 EXE는 사용하지 않습니다. MP3 변환은 포함하지 않습니다.

## 검증 범위
한양대의 학습 페이지, hycms 플레이어 및 영상 호스트는 실제 강의에서 확인했습니다. 확장 설치 및 실제 다운로드 성공은 아직 검증하지 않았습니다. 다른 영상 호스트 및 스트림 형식은 지원하지 않습니다.
